# Triage Labels

| 角色 | 本地状态值 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待评估 |
| needs-info | needs-info | 待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由 Agent 执行 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

普通任务的 Status 使用以上值。
Wayfinder 探索任务使用 issue-tracker.md 中的独立生命周期。
