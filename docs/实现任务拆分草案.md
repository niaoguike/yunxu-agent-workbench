# 云端 Agent 工作台实现任务拆分草案

状态：执行器复用路线的待确认拆分预览，共38张，覆盖PRD的49项验收；未发布正式实现工单。编号仅属于本草案，与技术决策地图编号无关，替代早先37张的草案。

## 依据与使用约定

- 依据[PRD v0.4](PRD.md)、[领域词汇表](../GLOSSARY.md)和[ADR-0002](adr/0002-reuse-agent-harnesses.md)。Python/FastAPI平台复用Claude Code与Codex的Agent loop，前端为React/TypeScript。
- 首先打通Claude Code原生会话与工具产物，再通过独立切片接入Codex；平台实现会话与事件适配、阶段和人工确认，不再实现替代执行器的内层工具循环。
- LangGraph仅为外层编排候选。存储、队列、沙箱和状态一致性仍待相应技术决策；当前草案不把旧候选当作已批准架构。
- 每票交付完整可演示行为，包含必要存储、后台接口、界面和行为验证，控制为一个全新上下文可实施的范围。
- 执行器事件夹具只验证平台逻辑；真实SDK/CLI及原生工具需要独立集成验证，不将夹具结果冒充成熟执行器已经兼容。
- 下列依赖是实现票之间的直接阻塞；落地前决策是现有地图中的同名外部前置条件。未决项解决前不得宣称对应任务已可立即开工。
- 账户与项目隔离、基本校验和必要授权随每票交付，不延后到统一加固票。执行器自带沙箱不自动等于完整云端隔离。
- 确认拆分后再逐票发布，保留真实外部前置条件；本轮不关闭或改写技术决策父票。

## 编号清单

1. **登录并管理私有项目** — 依赖：无实现票依赖。交付：用户可登录、创建和重开自己的项目，项目列表及访问限制真实可用。

2. **Claude Code 自由任务会话与执行记录** — 依赖：01。交付：在私有项目中使用已配置的 Claude Code 执行目标，查看真实原生会话回复、历史和平台执行状态。

3. **上传材料并查看项目文件** — 依赖：01。交付：上传材料、查看文件树和受支持内容，下载原文件，明确显示容量与失败原因。

4. **执行器工具调用与真实文件交付** — 依赖：02、03。交付：复用执行器原生工具在云端生成文件或运行脚本，平台展示工具活动并校验真实交付物。

5. **澄清问题与用户自设确认点** — 依赖：02。交付：Agent 能暂停等待关键答复；自由任务可要求先提交方案，获得确认后继续。

6. **项目任务排队与追加消息管理** — 依赖：02。交付：同项目任务有可见队列，运行中普通追加可编辑或撤回，跨项目按额度执行。

7. **ZIP 和公开仓库导入** — 依赖：03。交付：将压缩材料或指定公开仓库版本导入项目，查看来源、进度及导入结果。

8. **执行器、模型选择与长期指令** — 依赖：02。交付：分别选择执行器及其可用模型，配置长期指令，查看实际加载版本与认证状态。

9. **项目记忆查看、检索与管理** — 依赖：02。交付：查看、搜索、编辑或删除项目记忆，明确展示来源和作用范围。

10. **危险工具操作定向审批** — 依赖：04、05。交付：危险操作发生前展示目标与范围，用户批准或拒绝后才决定是否执行。

11. **立即纠正、停止和继续** — 依赖：04、06。交付：用户可明确纠正当前轮次、停止执行并保留资料，随后继续剩余工作。

12. **预算上限与无进展停止** — 依赖：04。交付：查看本次用量，在时间、调用或费用上限时保留部分成果并停止继续派发。

13. **运行应用并打开私有预览** — 依赖：04。交付：Agent 启动工作空间应用，用户在工作台查看受控运行预览和启动日志。

14. **联网研究与来源报告交付** — 依赖：04。交付：自由任务搜索并读取公开资料，交付可下载报告及可追查来源。

15. **CSV 分析与图表交付** — 依赖：04。交付：上传数据后按目标执行分析，得到图表、结果文件和口径说明。

16. **预置 Skill 选择与版本展示** — 依赖：04。交付：在自由任务选择或组合预置方法，Agent 按加载的版本工作，并展示实际使用情况。

17. **自主记忆保存与跨任务复用** — 依赖：09、04。交付：开启项目记忆后，Agent 自主保存有持久价值的信息，并供同项目新任务复用。

18. **记忆整理建议与可追查修订** — 依赖：09。交付：请求记忆审查，查看建议后执行明确的合并或删改，并保留变更记录。

19. **进程异常后的安全恢复** — 依赖：10、11、12。交付：页面断开或执行进程重启后，可以看到恢复状态并从已保存进度继续。

20. **自定义 Skill 导入与更新** — 依赖：16。交付：从文件包或公开来源安装方法包，在项目中启停、更新及卸载。

21. **MCP 连接与凭据配置** — 依赖：10。交付：配置远程或云端兼容的MCP连接，测试连通性，并在授权任务中调用工具。

22. **需求与方案阶段及人工确认** — 依赖：05、16。交付：创建需求开发任务，使用预置Skill生成需求基线和方案，确认后再推进。

23. **持久协作者创建与独立配置** — 依赖：08、10。交付：在任务中创建持久成员，配置职责、模型与权限，重开后可继续联系。

24. **交付版本比较与文件恢复** — 依赖：10、11。交付：查看和下载历史交付版本，确认影响后恢复选定项目文件。

25. **Codex 执行器端到端接入** — 依赖：08、10、11。交付：通过 App Server 在同一工作台启动并继续 Codex 任务，验证真实工具产物、审批及停止。

26. **扩展中心及插件生命周期** — 依赖：20、21。交付：发现并安装含工具、方法与资源的插件，按项目配置、更新和卸载。

27. **任务拆解与开发阶段交付** — 依赖：22。交付：已确认方案进入预置拆解与实现阶段，形成有完成条件的任务及实际代码变更。

28. **成员指派、消息队列与结果汇报** — 依赖：23、06。交付：用户或主Agent向成员指派任务，看到真实派发回执，并收到可追问的结果。

29. **环境休眠、唤醒与预览重启** — 依赖：13、19。交付：闲置计算可回收，项目文件保留；用户可唤醒工作空间并重启运行预览。

30. **扩展撤权与在途调用处理** — 依赖：26、11。交付：紧急停用或撤销凭据后，相关后续调用立即被阻止并展示在途结果。

31. **测试修复、人工验收与成果交付** — 依赖：27、12。交付：运行检查并有限修复，用户验收后整理可下载成果与运行说明。

32. **成员独立修改区与成果应用** — 依赖：28。交付：成员并行产出文件或代码，主Agent检查基线及冲突后应用到共享项目。

33. **需求变更、退回与确认失效** — 依赖：31。交付：开发或验收时提出修改，回到受影响阶段并保留未受影响的成果。

34. **协作整体停止、预算与恢复** — 依赖：32、19。交付：停止整个协作任务并恢复时，成员、指派和总预算保持一致。

35. **自由与需求开发模式切换** — 依赖：33、11。交付：在已有任务中切换模式，处理在途执行并保留目标、成果和阶段历史。

36. **归档、删除与回收区恢复** — 依赖：30、17、35、34、24、29。交付：收纳任务或项目，确认后回收并恢复资料，正确清理执行、权限与引用关系。

37. **固定任务评测与质量成本报告** — 依赖：07、14、15、18、36、25。交付：运行固定样本与故障场景，生成可复查的验收、质量、恢复和成本报告。

38. **干净环境启动与完整演示包** — 依赖：37。交付：在本地或受控环境按说明启动平台，完成代表任务并取得运行诊断与验收材料。

## 逐票验收草案

### 01：登录并管理私有项目

**交付行为：** 用户可登录、创建和重开自己的项目，项目列表及访问限制真实可用。

**依赖：** 无实现票依赖。

**落地前决策：** 工作台与后台交互的统一接口。

**PRD 验收关联：** AC-18。

- [ ] 从浏览器完成登录、创建、重开和退出，资料持久保留。
- [ ] 两个账户通过列表、详情或直接标识都不能互读项目。
- [ ] 首次启动包含最小可运行应用与验证命令，后续切片沿用。

### 02：Claude Code 自由任务会话与执行记录

**交付行为：** 在私有项目中使用已配置的 Claude Code 执行目标，查看真实原生会话回复、历史和平台执行状态。

**依赖：** 01「登录并管理私有项目」。

**落地前决策：** 双模式状态与人工确认的一致性规则。

**PRD 验收关联：** AC-01、AC-10、AC-46、AC-47。

- [ ] 通过官方 Agent SDK 创建并继续真实会话，认证未就绪时显示明确状态，不回退成未经说明的模型直调。
- [ ] 平台任务与原生会话标识分开保存，刷新可查历史与终态，重复提交不产生双重执行。
- [ ] 用执行器事件夹具验证平台投影，并独立通过真实 SDK 做集成验证；首条路径仅开放已可靠约束的能力。

### 03：上传材料并查看项目文件

**交付行为：** 上传材料、查看文件树和受支持内容，下载原文件，明确显示容量与失败原因。

**依赖：** 01「登录并管理私有项目」。

**落地前决策：** 工作空间与并行修改的归属。

**PRD 验收关联：** AC-18、AC-21。

- [ ] 上传成功与失败逐文件可见，同名替换有明确选择。
- [ ] 越界路径、跨账户访问和超过限制的输入被拒绝。
- [ ] 文本、Markdown、CSV和图片可预览，其他类型按能力下载而非假装解析。

### 04：执行器工具调用与真实文件交付

**交付行为：** 复用执行器原生工具在云端生成文件或运行脚本，平台展示工具活动并校验真实交付物。

**依赖：** 02「Claude Code 自由任务会话与执行记录」、03「上传材料并查看项目文件」。

**落地前决策：** 工作空间与并行修改的归属；工具扩展与阶段 Skill 的运行契约。

**PRD 验收关联：** AC-01、AC-13、AC-22、AC-47、AC-49。

- [ ] 原生工具和平台 MCP 的权限路径分别接入，未授权或越界能力不可因引擎自动允许规则绕过。
- [ ] 工具活动与文件来自真实执行器，产物检查后进入成果区，原生轮次结束不直接标记需求完成。
- [ ] 平台记录会话、轮次与原生动作的关联；失败与结果不明分开，不再自行实现替代执行器的模型—工具循环。

### 05：澄清问题与用户自设确认点

**交付行为：** Agent 能暂停等待关键答复；自由任务可要求先提交方案，获得确认后继续。

**依赖：** 02「Claude Code 自由任务会话与执行记录」。

**落地前决策：** 双模式状态与人工确认的一致性规则。

**PRD 验收关联：** AC-02、AC-40、AC-41。

- [ ] 将平台澄清与执行器可用的提问入口映射为可见卡片，回答回到正确任务和原生请求，未答复不代表同意。
- [ ] 确认绑定展示的内容与版本，重复答复不重复启动。
- [ ] 刷新后待答复卡和已保存答案仍可恢复。

### 06：项目任务排队与追加消息管理

**交付行为：** 同项目任务有可见队列，运行中普通追加可编辑或撤回，跨项目按额度执行。

**依赖：** 02「Claude Code 自由任务会话与执行记录」。

**落地前决策：** 双模式状态与人工确认的一致性规则。

**PRD 验收关联：** AC-06、AC-07。

- [ ] 同项目仅一个前台任务执行，项目队列可调整顺序。
- [ ] 普通追加显示已保存、待执行或已投递，进入投递边界后不误报取消成功。
- [ ] 关键等待暂停依赖工作，重复发送或恢复不会重复消费同一输入。

### 07：ZIP 和公开仓库导入

**交付行为：** 将压缩材料或指定公开仓库版本导入项目，查看来源、进度及导入结果。

**依赖：** 03「上传材料并查看项目文件」。

**落地前决策：** 工作空间与并行修改的归属。

**PRD 验收关联：** AC-22。

- [ ] ZIP越界、异常文件和超限内容失败且保留现有资料。
- [ ] 仓库导入记录来源和版本，私有账户连接不冒充已支持。
- [ ] 同名文件有明确处理，导入文本不能扩大执行权限。

### 08：执行器、模型选择与长期指令

**交付行为：** 分别选择执行器及其可用模型，配置长期指令，查看实际加载版本与认证状态。

**依赖：** 02「Claude Code 自由任务会话与执行记录」。

**落地前决策：** 长期指令与项目记忆的读写机制。

**PRD 验收关联：** AC-16、AC-29、AC-30、AC-46、AC-48。

- [ ] 新任务应用账户和项目规则，当前明确要求优先，其他账户不可读取。
- [ ] 切换执行器时明确创建新原生会话及交接目标与成果，不承诺原生历史无损迁移；默认设置不静默改写当前配置。
- [ ] 模型目录与认证可用性分开，不支持的组合可解释；真实执行器与模型记录不被默认值替代。

### 09：项目记忆查看、检索与管理

**交付行为：** 查看、搜索、编辑或删除项目记忆，明确展示来源和作用范围。

**依赖：** 02「Claude Code 自由任务会话与执行记录」。

**落地前决策：** 长期指令与项目记忆的读写机制。

**PRD 验收关联：** AC-17、AC-29。

- [ ] 记录有分类、摘要、正文、来源和版本，项目与账户访问隔离。
- [ ] 索引和正文按需读取，修改或删除后后续检索结果同步变化。
- [ ] 关闭后仍可清理旧记录，不把记忆删除当成删除历史对话。

### 10：危险工具操作定向审批

**交付行为：** 危险操作发生前展示目标与范围，用户批准或拒绝后才决定是否执行。

**依赖：** 04「执行器工具调用与真实文件交付」、05「澄清问题与用户自设确认点」。

**落地前决策：** 双模式状态与人工确认的一致性规则；工具扩展与阶段 Skill 的运行契约。

**PRD 验收关联：** AC-12、AC-49。

- [ ] 批准仅对本次展示的动作与参数有效，参数变化或权限收紧不能复用旧批准。
- [ ] 拒绝与审批异常不放行，已明确禁止的跨项目动作不提供通用放行按钮。
- [ ] 分别验证原生命令/文件操作与 MCP；批准方案和批准动作独立，无法可靠拦截的写能力不开放。

### 11：立即纠正、停止和继续

**交付行为：** 用户可明确纠正当前轮次、停止执行并保留资料，随后继续剩余工作。

**依赖：** 04「执行器工具调用与真实文件交付」、06「项目任务排队与追加消息管理」。

**落地前决策：** 双模式状态与人工确认的一致性规则。

**PRD 验收关联：** AC-08、AC-09。

- [ ] 按实际执行器能力投递立即纠正，返回真实接收、不支持或排队结果，不重复发送或假装已经插入。
- [ ] 停止分别处理请求回执与原生轮次终态，旧原生消息和迟到事件不能覆盖新轮次。
- [ ] 停止保留并暂停待执行输入，继续由明确操作触发，不撤销已发生效果。

### 12：预算上限与无进展停止

**交付行为：** 查看本次用量，在时间、调用或费用上限时保留部分成果并停止继续派发。

**依赖：** 04「执行器工具调用与真实文件交付」。

**落地前决策：** 完整方案的验证与评测方法。

**PRD 验收关联：** AC-14、AC-21。

- [ ] 原生用量、可观测工具动作和估算值分开；缺失数据标未知，不假定平台看到全部内部调用。
- [ ] 子任务最终使用同一总账，预留与结算防止并发穿透总额。
- [ ] 扩大预算需确认；达到上限或无进展时说明剩余工作，不能无限修复。

### 13：运行应用并打开私有预览

**交付行为：** Agent 启动工作空间应用，用户在工作台查看受控运行预览和启动日志。

**依赖：** 04「执行器工具调用与真实文件交付」。

**落地前决策：** 工作空间与并行修改的归属；成果验收与运行预览的生命周期。

**PRD 验收关联：** AC-05、AC-18。

- [ ] 区分静态文件与运行预览，展示启动中、可访问、停止和失败。
- [ ] 预览校验账户项目归属，与平台会话分开；旧入口不跨账户复用。
- [ ] 刷新不重复启动应用，后台失败不被误报为整个任务必然失败。

### 14：联网研究与来源报告交付

**交付行为：** 自由任务搜索并读取公开资料，交付可下载报告及可追查来源。
