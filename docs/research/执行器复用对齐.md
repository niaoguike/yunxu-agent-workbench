## 已核实事实

1. **统一宿主路由至执行器。** 参考源码 `Maker.createSession` 将执行分发给注册 Agent 的 `startSession` 或其他设备的宿主路由，平台 Session 与原生执行器分工。证据：[maker.ts](https://github.com/makecindy/cindy/blob/a5bd13c69b9f984ebee5fe32c737e489b6ab47dc/packages/maker-core/src/maker.ts)。本地已保存且比对过 blob，不由模块名推断实现。
2. **Claude Code 接入 Agent SDK。** 已完整下载的 `agents/claude-code/index.ts` 导入 `@anthropic-ai/claude-agent-sdk`，`startSession` 装配 resume、权限回调与工具前置处理，并管理原生会话。证据：[固定源码](https://github.com/makecindy/cindy/blob/a5bd13c69b9f984ebee5fe32c737e489b6ab47dc/packages/maker-core/src/agents/claude-code/index.ts)。该文件 blob 为 `91c99db8b3377050ba4d1466a4a8f4ade8921149`，与本地快照一致；本项目使用官方 Python 接口而非直接移植 TypeScript 宿主。
3. **Codex 使用双向 RPC 集成面。** 官方 App Server 提供 initialize、thread/start/resume、turn/start/steer/interrupt 和事件/审批；默认 stdio 传递 JSONL，协议采用省略 jsonrpc 头的 JSON-RPC 2.0 消息。证据：[Codex App Server](https://developers.openai.com/codex/app-server/)。实际抓取重定向至 [当前官方页面](https://learn.chatgpt.com/docs/app-server)。本地参考 `app-server/client.ts` 实现传输初始化、请求与关闭，blob `575656c772704c55778f83f38af3e6a3eb241d52` 已比对：[固定源码](https://github.com/makecindy/cindy/blob/a5bd13c69b9f984ebee5fe32c737e489b6ab47dc/packages/maker-core/src/agents/codex/app-server/client.ts)。
4. **Python 可接入 Claude Agent SDK。** 官方 Python 参考提供 `ClaudeSDKClient`、会话输入、权限处理和中断等接口。自动放行规则可能先于 can_use_tool，不能只看回调存在就保证所有工具必经平台审批。证据：[Python SDK 参考](https://code.claude.com/docs/en/agent-sdk/python)。
5. **模型客户端与完整执行器不同。** 官方说明区分模型客户端 SDK、自带循环的 Agent SDK 与更直接的产品生命周期集成面；本项目选择后两者承接内层执行，平台控制业务流程。证据：[Agent SDK Overview](https://code.claude.com/docs/en/agent-sdk/overview)、[Codex as a platform](https://developers.openai.com/blog/codex-as-a-platform)。
