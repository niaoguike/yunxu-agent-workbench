## 本批实现：工具执行保护

参考 `packages/maker-core/src/agents/shared/loop-guard.ts` 与 `tool-loop-review.ts` 的职责拆分，先落实确定性的执行预算和重复失败保护，不宣称已具备其辅助模型复核能力。

每个原生运行有独立保护器。仅在连续工具名、参数和结果一致且结果失败时累计重复次数；三次记录告警，八次请求停止。成功或结果变化会清除连续失败计数。成功重复调用不会被判为失败循环，只有明确的总动作预算到期才停止。事件保存原因、计数与证据哈希，不保存额外原始参数。

Codex 从原生工具完成事件获得结果，通过 turn/interrupt 停止并等待原生终态，再转为带原因的失败。Claude 从 PostToolUse/PostToolUseFailure hook 获得证据，使用 SDK interrupt；此路径尚未使用真实 Claude 凭据验证。平台事件和现有失败显示承接保护结果，文件保留。

验证：4 项保护器场景及真实 worker 子进程协议回归，确认保护触发后不提前冒充原生已经停止。此前完整套件 41 passed / 1 skipped，新增协议回归所在子集 12 passed，2 subtests passed。
