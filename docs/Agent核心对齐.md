## 协作与权限

未启用协作的主任务只获得记忆工具。协作者仅获得记忆和向主任务汇报工具，不能递归创建成员。服务端依据当前运行验证项目、父任务与角色。桥使用每轮随机令牌连接本机临时端口，不透传账户凭据。

Auto 仅预批准平台控制的 workbench MCP 工具，第三方 MCP 不继承；Ask 保留审核。服务端仍检查记忆开关、协作授权、文件路径及基线。workbench 为保留扩展名。

## 复核策略

脱敏限长证据交给独立工作区中的辅助运行，禁用工具、MCP、插件与项目指令，要求结构化 continue/stop。每轮最多3次复核，每次20秒；超时或结果无效时继续并给予20次动作宽限，总预算仍生效。证据变化使旧结论失效，主任务结束取消未完成复核。原始证据不额外写入平台事件。

直接运行器保留确定性保护兼容路径；平台运行启用自适应复核。
