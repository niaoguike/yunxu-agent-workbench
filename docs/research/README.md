## 阅读顺序

1. [任务与消息调度](任务与消息调度.md)：发送、排队、纠正、队列控制与恢复。

3. [记忆与 Skills](记忆与Skills.md)：归属、开关、加载快照和宿主装配。
4. [成果与预览](成果与预览.md)：实际文件交付、访问控制、预览生命周期与来源隔离。
5. [工具扩展对齐](工具扩展对齐.md)：扩展类型、安装更新、项目启停、凭据与云端适配。
6. [个性化与记忆对齐](个性化与记忆对齐.md)：长期指令、自主写入、记忆分类、检索和管理。
7. [Agent 协作对齐](Agent协作对齐.md)：持久成员、会话与指派、独立权限、文件冲突与生命周期。
8. [执行器复用对齐](执行器复用对齐.md)：Agent SDK 与 App Server 的实际接入面、源码路由和云端适配边界。

第 5–7 项对应 PRD v0.2 的新增对齐范围。较早笔记中的“仅平台预置方法”“逐条确认候选记忆”及“只使用临时子 Agent”等建议不再代表当前产品选择。

早期核心模块笔记保留在 [源码参考](../Cindy源码参考.md)。本轮详细笔记优先说明实际核查范围；“接口存在”“提示词要求”和“运行时已保证”属于不同证据强度。

## 与产品文档的映射

| PRD 范围 | 调研依据 | 本产品的独立取舍 |
| --- | --- | --- |
| T-01 项目并发 | 单会话并发保护、任务工作空间分配 | 首版共享项目资料，选择项目级串行；不是宣称参考实现全项目串行 |
| T-02 追加与纠正 | Session 与宿主 queue/steer 控制 | 把普通发送和立即纠正做成可理解的两个动作 |
| T-03/T-04 停止与管理 | 运行状态与组织状态、停止与队列控制；参考协调器 stop 默认清空队列，保留需显式参数 | 本产品独立选择停止后保留并暂停消息，避免丢失用户输入；归档、删除、回收区分别定义 |
| A-02/A-03 授权 | 动作审核、审批等待、过时结果失效 | 云端项目范围内常规操作允许，越界禁止，危险操作定向确认 |
| D-01 成果 | 回复引用的真实路径、大小与归属核对 | 增加显式成果卡片及版本，不仅解析聊天文本 |
| D-02/D-03 检查与修复 | 无法从局部交付代码证明完整自动验收 | 作为本产品独立设计，要求检查证据与有限修复 |
| V-01/V-02 预览 | 静态快照访问控制和资源清理 | 自行设计云端应用运行预览，不把本地预览当成现成云端部署 |
| K-01/K-04/K-05 扩展与 Skills | 加载快照、包安装事务、工具声明及项目策略宿主 | 纳入用户安装导入、自定义 MCP、项目覆盖与撤权；第三方桌面代码不能原样作为云端安全实现 |
| K-02 记忆 | owner/project 范围、分类、检索、开关和清理 | 开启后按价值自主写入，无逐条确认；用户可查看修订删除，偏好分类不自动跨项目传播 |
| K-06/K-07 个性化 | 账户归属的长期指令保存、产品帮助与模型设置契约 | 本产品云端保存，长期指令与自主记忆分开；动态指令装配仍需本项目实现并测试 |
| E-03 至 E-06 协作 | Worker 持久身份、实际创建和消息派发、独立权限与工作目录 | 保留临时子 Agent，并增加用户可见的持久协作者；云端写入隔离与汇总应用需独立实现 |
| K-03 模型 | 能力差异和实际运行快照 | 首版切换默认下一轮生效，不承诺热迁移全部上下文 |
| 初始产品限制 | 没有上游性能数据支持这些数值 | 容量、时长、队列与回收期是可配置初始产品值，非实测最优 |

## 输出状态

[PRD](../PRD.md) v0.4 已纳入成熟执行器选择与能力差异，平台复用 Claude Code/Codex loop。当前技术路线见 [ADR-0002](../adr/0002-reuse-agent-harnesses.md)，原生循环候选已被取代。PRD 不包含参考项目名称；双模式、七阶段方法和人工确认属于本产品设计，细节仍供整体评审。

调研验证的是源码静态行为及可追到的调用链。跨机运行、云端隔离、进程故障恢复、浏览器预览安全和模型质量尚未经过运行测试；对应验收场景作为本项目后续实现要求。
