# 成果与预览：源码调研

研究日期：2026-11-03。固定提交 `a5bd13c69b9f984ebee5fe32c737e489b6ab47dc`。四份文件已下载到 `.references/research-product/` 并使用 `git hash-object` 与基准提交 blob ID 比对一致。本研究仅静态阅读，未运行第三方项目。

## 1. 把真实文件交付与文本提及分开

**事实**：[replyArtifacts.ts](https://github.com/makecindy/cindy/blob/a5bd13c69b9f984ebee5fe32c737e489b6ab47dc/apps/desktop/src/main/companion-cloud/replyArtifacts.ts) 的 `collectReplyReferences` 排除代码围栏里的示例，并提取正文中的文件引用。`replyArtifactAttachments` 会解析真实路径、检查工作目录归属、隐藏路径、文件存在性与大小，才形成附件；不会因正文写着一个路径就证明文件已交付。它是 companion 消息镜像的附件逻辑，不代表所有任务都有统一成果清单。

**本产品建议**：在结果区域显示可实际打开或下载的成果卡片，包含名称、类型、版本和生成时间。只有文本声明而无文件时不能显示可下载；临时文件与最终交付分开。源码中的交付扩展名白名单不应直接复制成我们全部产物支持范围。

**验收场景**：Agent 回答“已生成 report.md”，但文件不存在，成果区应标记缺失并阻止该交付条件通过。

## 2. 预览操作需要校验来源和对象归属

**事实**：[previewGate.ts](https://github.com/makecindy/cindy/blob/a5bd13c69b9f984ebee5fe32c737e489b6ab47dc/apps/desktop/src/main/cindy-brain/previewGate.ts) 的 `parseGhostPreviewUrl`、`resolveGhostPanelMedia` 校验哈希和引用形状，并通过归属账本与真实 MIME 判定可预览对象。[previewSlot.ts](https://github.com/makecindy/cindy/blob/a5bd13c69b9f984ebee5fe32c737e489b6ab47dc/apps/desktop/src/main/cindy-brain/previewSlot.ts) 的 `GhostPreviewSlot` 检查插件启用状态、预览声明和允许的 URL 范围。这两条属于插件面板入口，不是通用云端应用预览实现。

**本产品建议**：任务只能打开本项目授权成果，预览链接不是任意地址透传。用户能理解的表现为“无权访问”“成果不存在”“预览已失效”，详细网络校验放技术方案。关闭任务或撤销访问后，旧预览不可继续绕过权限。

**验收场景**：复制其他用户的成果标识到预览入口，不得取得文件或揭露其内容。

## 3. 预览有独立生命周期

**事实**：[html-preview.ts](https://github.com/makecindy/cindy/blob/a5bd13c69b9f984ebee5fe32c737e489b6ab47dc/apps/desktop/src/main/file-browser/html-preview.ts) 的 `createHtmlPreview` 创建临时预览服务，`current()` 检查是否关闭、取消或来源已失效；`close()` 终止连接并清理临时资源。请求处理验证 Host、请求来源、访问 Cookie 和方法，来源失效时返回 410。此处是 HTML 快照预览，不能据此证明任意后端应用都可代理运行。

**本产品建议**：区分持久成果与临时运行预览；文件保留不保证服务进程在线。界面分别显示启动中、可访问、已停止和失败，可重新启动。计算环境休眠时关闭运行预览；再次访问应明确唤醒，而非展示永久在线承诺。应用运行预览需要本项目独立实现鉴权和端口访问控制。

**验收场景**：项目休眠后文件仍可下载，运行预览显示已休眠；唤醒成功后生成有效入口，旧授权不能跨账户复用。

## 4. 静态文件预览和运行应用预览分别定义

**事实**：`previewLocation` 接受本地、其他设备和 SSH 来源，对 HTML 文件类型及相应目录约束做检查；`createHtmlPreview` 只暴露 GET/HEAD 请求并读取受控资源。它不是用户应用写接口或完整网站部署。

**本产品建议**：静态文件预览用于报告和 HTML 等内容；应用预览用于云端工作空间里启动的开发应用。两者都需要权限，但不能共用含混的“已部署”状态。首版不提供公开发布或长期托管承诺。

**验收场景**：应用预览能发起其工作空间内受控后端请求，但不能访问平台的登录凭据、其他项目或宿主网络；静态快照不因缺失运行后端而被宣称应用已验证。
