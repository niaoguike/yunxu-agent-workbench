## 指派与合并故障注入

每策略 200 次请求。稳定 ID 重复逻辑指派 0；每次新 ID 基线重复逻辑指派 190。重启回执、载荷冲突、文件并发冲突与重复应用共 40 / 40 项不变量通过。

此项使用真实控制面代码和 SQLite，调度出口被替换为不执行模型的记录边界。统计是重复逻辑指派，不能表述为已避免同等数量真实模型执行。

## 结论边界

这是 3 个固定任务、每模式 2 次的小样本工程验收，不能代表开放任务泛化成功率。没有显著性检验、吞吐压测或付费成本结论。循环数据有意对比永久失败与明确授权的暂时重试，不代表业务错误分布。证据引用检查核对结构和必要引用覆盖，不替代专家对报告质量的盲评。
