# 本地自动化、聊天交接与插件包

复用单进程 SQLite 工作台和真实执行器。计划支持每日/每周、北京时间/UTC，默认停用、Ask。每个时间槽唯一派发，上次未结束则跳过；超过 60 秒未派发记录 missed，重启不补跑。创建新主任务，执行记录关联任务。支持立即运行、编辑和启停。

Slack Socket Mode、Telegram getUpdates 在本机主动连出，默认停用。绑定唯一聊天与用户、独立接收/发送授权；不处理机器人及非文本消息。凭据使用连接 ID 派生的服务器环境变量，API 不收回密钥，执行器不继承渠道环境变量。记录去重、线程映射、失败与结果不明；持久接收后 ACK，再派发。任务完成后仅在授权聊天回传摘要及成果名称；手动交接允许在同一渠道回复继续原任务。发送超时/服务中断标 unknown，不自动重发；明确失败可手动重试。

插件包 JSON 包含来源/版本/Skill 与 stdio MCP，复用既有校验，原子导入且默认停用。展示原内容和完整性哈希，未做安全审核；整体启停沿用停止执行/失效会话规则。所有 API 验证项目所有权，回收项目不执行也不收发。

验收使用离线运输夹具，不发送真实外部消息。真实 Slack/Telegram 和模型调用需用户配置后另行验证。
