# Personal Agent 实施地图

## Notes
用户已授权按照 product-parity-roadmap.md 顺序实施。代码按单进程控制面和现有原生执行器复用，不替换现有工作台。

## Decisions-so-far
- 目标独立持久化，带修订号；完成由用户逐项确认成功标准证据。持续责任与关注项沿用事件队列，成功后安排复查。
- 账户主助手绑定一个个人项目和主任务；首页无须创建项目即可交办，汇总账户目标和个人项目协作报告。
- 模型通过 goal_list / goal_create / goal_schedule 管理目标与下一步；Goal 默认 Ask，也可由用户选择原生 Auto 风险审核。
- Google 凭据加密存储，子进程过滤 Google/Vault 环境变量。外部数据仅路由给订阅目标，邮件和日历写操作要求显式用户批准。
- 云浏览器为可选 Docker 适配，CDP 不发布端口，凭据与工作台不挂载进容器。当前仍为可信开发部署，未证明生产级隔离。
- 原生 MCP 审批接入平台 Ask；未知结构化表单保持拒绝。MCP stdio 显式 UTF-8，真实中文草稿创建验证通过。

## Fog
- Google OAuth 缺应用配置、Docker daemon 不可用；真实账户和浏览器联调未完成。
- 实时全双工语音、安静时段、跨项目自动个人记忆、生产级 VM/网络出口控制仍未实现；浏览器语音输入不能等同实时通话。
- 条件关注的业务判断依赖真实执行器；平台协议测试不证明所有开放目标能够正确自主推进。
