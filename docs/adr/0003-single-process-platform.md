# ADR 0003: 单进程持久化工作台

状态：实现默认值，2026-11-03。

首个可运行版本使用 FastAPI 单进程、SQLite WAL、持久事件表和 asyncio 项目锁。一个项目串行运行，跨项目可以并行。队列先落库再派发；重启恢复未派发任务，执行中任务标记为结果不明，需要人工检查后继续。禁止将 uvicorn workers 设置为大于 1。上线多实例前必须换成数据库租约和外部 worker，不能把进程锁当分布式锁。

执行器层采用 ADR 0002。默认关闭执行，需要显式配置 Docker 或 trusted-local。Docker 不是已验证的多租户安全边界；本版本不对公网开放不可信注册执行。没有凭据时不生成演示 Agent 回复。

阶段 Skill 作为受版本快照约束的指令下发。阶段结束必须有指定文件，随后由人确认需求、方案、验收；检查记录是否真实、语义是否通过仍由原生执行器提供证据与人确认，平台不伪造测试分数。成果快照保留下载，工作区编辑使旧确认失效。

MCP 首版支持无明文密钥的 stdio 配置。自动记忆使用显式 opt-in 和可见 JSON 提案文件导入，不把历史对话当长期记忆。成员独立工作区和原生会话，按文件基线哈希解决回写冲突。
