# CSV 交互成果

本地 CSV 工具解析上传文件，生成任务中的图表卡片。支持分类/数值字段、柱状/折线、等值筛选、完整数据表。图表展示前 100 行且明确提示，不聚合。CSV 限 UTF-8、2 MB、1000 行、40 列，拒绝不规则记录及非有限数值列。

SQLite 保存数据快照及不可变配置版本，工作区保存 CSV；每次保存生成新版本，并写入对话与事件。可查看历史版本、在其基础上保存新版本；并发更新按基线版本拒绝覆盖。关闭重开自动恢复任务及已保存图表。所有接口检查任务所有权与项目回收状态。

生成和修改图表由明确标注的本地工具完成，不伪装模型回复。按钮可将当前图表、文件与筛选条件提交真实 Agent 分析；执行器未配置时明确报错。当前不增加任意 HTML 或应用控制。

真实 Agent 通过现有 MCP 桥接的 chart_list / chart_revise 读取及修改当前任务图表；solo/leader 可见，worker 不继承。修改使用同一验证与版本事务，模型返回不能绕过字段验证、任务范围和版本冲突检查。页面每 5 秒读取最新图表。
