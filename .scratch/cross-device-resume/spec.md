# 跨设备继续工作

复用现有账户、持久任务、消息、项目文件和后台执行。账户保存最近打开任务，新设备登录后恢复项目和任务。恢复位置必须验证所有权，回收项目不可恢复。任务事件按游标补拉；网络恢复或窗口聚焦立即刷新，成功后清除连接提示。

部署要求：设备访问同一后端，数据目录挂持久卷，单 API 进程。浏览器断开不停止任务；服务进程异常退出沿用暂停并人工检查的恢复规则，不重放工具。

## 当前范围调整

按用户要求暂缓云端部署与跨设备使用，优先本地持久化和关闭重开后的记录追溯。保留既有账户级恢复位置能力。复用同一数据目录恢复账号、对话、任务、事件与文件；不承诺关闭后端后任务继续运行或保存未提交的输入。
